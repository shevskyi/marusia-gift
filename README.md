# Марусю, це тобі

Сайт: https://shevskyi.github.io/marusia-gift/

Сторінка-подарунок: конверт розкривається, а мультфільм вилітає з нього як листівка.

Усе працює на статичному хостингу: без збірки, зовнішніх бібліотек, API чи ключів. Відео, постер, українські субтитри та шрифти з ліцензіями зберігаються локально. Усі посилання відносні й підходять для GitHub Pages у вкладеному шляху.

Кнопки: відтворення / пауза, перемотування, звук, субтитри, повний екран, повтор і збереження відео. Клавіші: пробіл / K — пауза, стрілки — ±5 секунд, M — звук, F — повний екран. На iPhone використовується системний відеоплеєр; якщо браузер забороняє повний екран, плеєр заповнює вікно. Гучність на iPhone регулюється також кнопками пристрою.

Враховано зменшення руху. Без JavaScript залишається пряме посилання на мультфільм. Відео H.264 / AAC, 1600×900, 1:48,27, faststart. Голоси в мультфільмі синтезовані.

Локальна перевірка з цієї папки: `python3 -m http.server 3042 --bind 127.0.0.1`.

Параметр `?quiet` вимикає паперові звуки й залишає гучність відео на нулі для тихої перевірки. Звичайне посилання запускає звук після натискання на сердечко.

GitHub Pages: гілка `main`, каталог `/`, файл `.nojekyll` вимикає обробку Jekyll.
